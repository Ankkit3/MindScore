About the project

An academic project, built like a product

MindScore is an academic machine-learning project exploring how behavioral, lifestyle, academic, and stress-related indicators can be used to predict a numerical mental health score.

The project demonstrates data preprocessing, feature engineering, machine learning, regression, API development, and frontend/backend integration.

Important: MindScore is an educational and informational project. It is not a medical diagnosis or a substitute for professional mental-health advice.
